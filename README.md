# Toy Tales 🧸

A React CRUD application for managing Andy's toy collection.

The application connects a React frontend to a `json-server` REST API and allows users to view, create, like, and donate toys.

## Features

Toy Tales supports full CRUD functionality:

- **GET** — Fetch and display all toys when the application loads.
- **POST** — Create a new toy through the form.
- **PATCH** — Increase a toy's likes when the Like button is clicked.
- **DELETE** — Donate a toy and remove it from the collection.

## Technologies

- React
- JavaScript
- Vite
- JSON Server
- Fetch API
- Vitest
- React Testing Library
